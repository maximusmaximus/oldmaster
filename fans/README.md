# Fan mosaics

Every mosaic shared from **Try your own** is stored here.

```
fans/index.json          newest first
fans/{id}/meta.json      title, cols, rows, createdAt
fans/{id}/emoji.txt      glyph grid, one row per line
fans/{id}/mosaic.jpg     medium JPEG of the live mosaic
```

`{id}` is `fan-` plus 12 hex characters. No names or emails — only the work.
The site lists these under Gallery → Fans and serves `/fan/{id}` so a friend
can open the picture and make their own Emoji New Master.

See [METHODS.md](../METHODS.md) §7.
